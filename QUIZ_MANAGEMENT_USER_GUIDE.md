# Quiz Management System - User Guide

## Overview
The Quiz Management System provides comprehensive tools for creating, managing, and taking quizzes within the Thuto Thebe educational platform. This guide covers all user roles and their respective capabilities.

## Getting Started

### Accessing Quiz Management
1. **Login** to the Thuto Thebe platform
2. Navigate to the **sidebar menu**
3. Look for the **"Quizzes"** or **"Quiz Management"** option (varies by role)
4. Click to access the quiz interface

## User Roles and Capabilities

### 👨‍🎓 Students
**Navigation:** Sidebar → "Quizzes"

#### What Students Can Do:
- View available quizzes for their enrolled courses
- See quiz details (time limit, points, description)
- Check quiz availability status and time remaining
- Take quizzes when available
- View quiz results after completion

#### Student Interface Features:
- **Quiz Status Indicators:**
  - 🟢 **Available**: Quiz is ready to take
  - 🔵 **Upcoming**: Quiz will be available soon
  - 🔴 **Expired**: Quiz deadline has passed
- **Time Management:** Real-time countdown showing time remaining
- **Course Filtering:** Filter quizzes by enrolled courses
- **Clear Actions:** Take quiz or view results based on status

### 👨‍🏫 Teachers
**Navigation:** Sidebar → "Quizzes"

#### What Teachers Can Do:
- View all quizzes they've created
- Create new quizzes for their courses
- Edit existing quiz details
- Activate/deactivate quizzes
- Delete quizzes
- Monitor quiz submissions and results
- Filter quizzes by course and status

#### Teacher Interface Features:
- **Comprehensive Management:** Full CRUD operations
- **Advanced Filtering:** Search by title, code, status, or course
- **Status Management:** Easy activation/deactivation controls
- **Visual Indicators:** Color-coded status badges
- **Quick Actions:** Edit, delete, and status toggle buttons

### 🏫 School Administrators
**Navigation:** Sidebar → "Quiz Management"

#### What School Admins Can Do:
- Oversee all quizzes in their school
- Monitor quiz usage across all courses
- Manage quiz settings and policies
- Access comprehensive quiz analytics
- Support teachers with quiz management

## Using the Quiz Management Interface

### For Teachers: Managing Quizzes

#### Creating a New Quiz
1. Click the **"Create Quiz"** button (top-right corner)
2. Fill in quiz details:
   - **Title**: Descriptive name for the quiz
   - **Code**: Unique identifier
   - **Description**: Optional quiz description
   - **Course**: Select the associated course
   - **Time Limit**: Duration in minutes
   - **Total Points**: Maximum possible score
   - **Start/End Dates**: Availability window
3. Configure quiz settings:
   - **Grading Type**: Auto, Manual, or Hybrid
   - **Max Attempts**: Number of allowed attempts
   - **Show Results**: Whether to display results immediately
4. Save the quiz

#### Managing Existing Quizzes
1. **Search and Filter:**
   - Use the search bar to find specific quizzes
   - Filter by status (Draft, Published, etc.)
   - Filter by course
2. **Quiz Actions:**
   - 👁️ **View**: See quiz details and statistics
   - ✏️ **Edit**: Modify quiz settings and content
   - ▶️/⏸️ **Activate/Deactivate**: Control quiz availability
   - 🗑️ **Delete**: Remove quiz permanently

#### Quiz Status Management
- **Draft**: Quiz is being created (not visible to students)
- **Published**: Quiz is available for students to take
- **In Progress**: Students are currently taking the quiz
- **Completed**: Quiz deadline has passed
- **Archived**: Quiz is no longer active

### For Students: Taking Quizzes

#### Finding Available Quizzes
1. Access the "Quizzes" section from the sidebar
2. Browse available quizzes for your courses
3. Use the course filter to narrow down options
4. Check quiz status and time remaining

#### Taking a Quiz
1. **Check Availability**: Ensure quiz shows "Available" status
2. **Review Details**: Check time limit and point value
3. **Click "Take Quiz"**: Start the quiz session
4. **Complete Questions**: Answer all questions within time limit
5. **Submit**: Submit your responses before time expires

#### Viewing Results
1. **After Completion**: Results may be available immediately
2. **Access Results**: Click "View Results" for completed quizzes
3. **Review Performance**: See your score and feedback

## Best Practices

### For Teachers
1. **Plan Ahead**: Create quizzes well before the intended start date
2. **Test First**: Take your own quiz to ensure it works correctly
3. **Clear Instructions**: Provide detailed descriptions and expectations
4. **Appropriate Timing**: Set reasonable time limits for quiz completion
5. **Regular Monitoring**: Check quiz submissions and student progress

### For Students
1. **Check Regularly**: Monitor for new quiz announcements
2. **Prepare in Advance**: Review course materials before taking quizzes
3. **Time Management**: Start quizzes with sufficient time remaining
4. **Technical Preparation**: Ensure stable internet connection
5. **Read Carefully**: Review all questions and instructions thoroughly

## Troubleshooting

### Common Issues and Solutions

#### For Students:
**Problem**: Can't see a quiz that should be available
- **Solution**: Check if you're enrolled in the correct course
- **Solution**: Verify the quiz start date hasn't passed
- **Solution**: Contact your teacher if the issue persists

**Problem**: Quiz timer isn't working correctly
- **Solution**: Refresh the page and restart the quiz
- **Solution**: Ensure JavaScript is enabled in your browser
- **Solution**: Contact technical support if problems continue

**Problem**: Can't submit quiz responses
- **Solution**: Check your internet connection
- **Solution**: Try submitting individual questions first
- **Solution**: Contact your teacher immediately if near deadline

#### For Teachers:
**Problem**: Students can't access published quiz
- **Solution**: Verify quiz status is set to "Published"
- **Solution**: Check start and end dates are correct
- **Solution**: Ensure quiz is activated (not deactivated)

**Problem**: Quiz not appearing in course
- **Solution**: Confirm correct course is selected
- **Solution**: Check if quiz is properly saved
- **Solution**: Verify course enrollment settings
