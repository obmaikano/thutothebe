# School Admin Role Functions Documentation

## Overview
School Administrators manage school-wide operations, staff, students, courses, and administrative functions. They oversee the entire school ecosystem within the Thuto Thebe platform.

## Navigation Structure
**Primary Path:** `/app/school-admin-*` (role-specific routes)
