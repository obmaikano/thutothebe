# Regional Officer Role Functions

## Overview
Regional Officers oversee schools in their region, conduct visits, manage reports, and monitor performance and compliance.

## Navigation Structure
- Dashboard
- Schools Map
- School Visits
- Assessment Reports
- Regional Metrics
- Reports (School Performance)
- Monitoring (Regional Usage)
- Messages (All, Contacts)
- Schedule
- Help

## Core Functions & Status
| Function                  | Status                | Description                                      |
|--------------------------|-----------------------|--------------------------------------------------|
| Schools Map               | Fully Implemented     | Geographic view of schools                       |
| School Visits             | Fully Implemented     | Schedule/manage school visits                    |
| Assessment Reports        | Fully Implemented     | Create/view assessment reports                   |
| Regional Metrics          | Fully Implemented     | View regional performance data                   |
| Reports                   | Fully Implemented     | Generate/view school performance reports         |
| Monitoring                | Fully Implemented     | Monitor LMS usage and compliance                 |

| Help                      | Partially Implemented | Support/documentation                            |

## Feature Descriptions
- **Schools Map:** Visualize and manage schools geographically.
- **School Visits:** Plan and record school visits.
- **Regional Metrics:** Access analytics for regional performance.

## Implementation Details
